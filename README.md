## ВВЕДЕНИЕ

### Актуальность работы

В современной электронной коммерции веб-приложение является ключевым инструментом для успеха компании. Согласно исследованиям, более 80% потребителей начинают поиск товаров в интернете, а значительная часть совершает покупки через веб-платформы. Мебельный бизнес не исключение — создание удобного, функционального и визуально привлекательного онлайн-магазина является критически важным для конкурентоспособности.

Рынок мебели в Кыргызстане активно развивается, и наличие качественного интернет-магазина позволяет компании охватить гораздо более широкую аудиторию, чем при работе только с физическими магазинами. Потребители ценят удобство, доступность информации о товарах, прозрачность цен и возможность сравнить варианты перед покупкой.

Данная курсовая работа посвящена разработке полнофункционального веб-приложения для онлайн-магазина мебели "Мурас". Проект демонстрирует практическое применение современных технологий веб-разработки: HTML5 для структуры, CSS3 для стилизации, JavaScript (ES6+) для интерактивности и LocalStorage API для хранения данных на клиенте.

### Цель и задачи

**Цель работы:** Разработать полнофункциональное веб-приложение магазина мебели "Мурас" с поддержкой каталога товаров, системой корзины, выбором способов оплаты и доставки, переключением тем оформления и адаптивным дизайном для всех устройств.

**Основные задачи:**
1. Провести анализ требований и спроектировать архитектуру приложения
2. Реализовать адаптивный пользовательский интерфейс на HTML5 и CSS3
3. Разработать интерактивный функционал на JavaScript (ES6+)
4. Реализовать систему управления корзиной товаров с сохранением состояния
5. Создать механизм переключения светлой/тёмной темы с сохранением выбора пользователя
6. Оптимизировать производительность и обеспечить совместимость с современными браузерами
7. Документировать код и процесс разработки с примерами реализации

Приложение "Мурас" предоставляет следующие возможности пользователям:

1. **Каталог товаров** - Просмотр мебели в 5 категориях (стулья, кресла, шкафы, диваны, кухни) с более чем 40 различными моделями
2. **Информация о товарах** - Для каждого товара отображаются: название, цена в сомах, артикул, дата добавления, подробное описание, фотография

6. **Адаптивный дизайн** - Оптимальный отображение на всех размерах экранов от 320px до 2560px
7. **Интерактивные элементы** - Анимации, эффекты наведения, плавные переходы для улучшения UX
8. **Справка и помощь** - Информация о доставке, оплате, политике возврата

## АНАЛИЗ ТРЕБОВАНИЙ

### Функциональные требования

#### 1. Система категоризации товаров

**Детальное описание:**
- Разделение товаров по 5 основным категориям с отдельными JS модулями для каждой категории
- Каждая категория имеет свою страницу/раздел с полным списком товаров, отсортированными по артикулу
- Возможность быстрого переключения между категориями через меню навигации в заголовке с иконками
- Отображение количества товаров в каждой категории как на кнопке меню, так и в шапке страницы
- Быстрая загрузка товаров выбранной категории без перезагрузки страницы (AJAX-подход с DOM)
- Плавная анимация переходов между категориями (fade-in/fade-out 0.3s)
- Запоминание последней просмотренной категории в localStorage
- Индикатор активной категории в меню навигации
- Возможность перейти в категорию прямо со ссылки или с главной страницы

**Примеры категорий и их характеристики:**
- **Стулья:** 15+ моделей, цены 1200-5300 сом, различные материалы (дерево, пластик, металл, ткань)
- **Кресла:** 12+ моделей, цены 3500-15000 сом, различные типы (офисные, для отдыха, геймерские)
- **Шкафы:** 10+ моделей, цены 8000-50000 сом, встроенные и напольные варианты
- **Диваны:** 15+ моделей, цены 12000-80000 сом, различные размеры и конфигурации
- **Кухни:** 8+ комплектов, цены 20000-120000 сом, модульные системы

#### 2. Корзина покупок

**Расширенная функциональность:**
- Пользователь может добавлять товары в корзину через кнопку "В корзину" с визуальной подтверждением
- Возможность увеличения/уменьшения количества товара в корзине через счётчики (+-кнопки или ввод числа)
- Удаление товара из корзины с подтверждением или без
- Автоматический расчёт общей стоимости товаров в реальном времени при любом изменении
- Применение скидок при заказе от определённой суммы:
  - Бесплатная доставка при заказе на сумму ≥ 50000 сом
  - Дополнительный кэшбэк за заказ ≥ 100000 сом (5% возврата)
  - Специальные предложения при покупке 3+ товаров (-10% на 3-й товар)
- Сохранение состояния корзины в LocalStorage для восстановления при перезагрузке страницы
- Очистка корзины при оформлении заказа и отправке на страницу спасибо
- Отображение количества товаров на иконке корзины в заголовке
- Уведомление при добавлении товара ("Товар добавлен в корзину")
- Запрет добавления товара если его нет в наличии

**Расширенные возможности:**
- История корзины (возможность восстановить удалённый товар)
- Сравнение товаров прямо в корзине
- Возможность сохранить корзину и отправить по email

#### 3. Система оплаты и доставки

**Способы оплаты (с подробной реализацией):**
- **Картой** (кредитная/дебетовая карта) - требуется ввод:
  - Номера карты (16 цифр с проверкой Luhn алгоритма)
  - CVV кода (3-4 цифры)
  - Срока действия (месяц/год)
  - Имени держателя карты
  - Проверка суммы и преждевременное завершение при ошибке
- **Наличными при получении** - без дополнительных данных, требуется подтверждение готовности к оплате

**Способы доставки (с расчётом):**
- **Стандартная доставка:** 2500 сом, 3-5 рабочих дней, по всей стране
- **Экспресс доставка:** 5000 сом, 1-2 рабочих дня, в пределах города
- **Самовывоз:** бесплатно, 1 рабочий день, из магазина на ул. Правда, 126
- **Бесплатная доставка:** при заказе на сумму ≥ 50000 сом (стандартная)

**Расчёт доставки и налогов:**
- Автоматический расчёт стоимости доставки на основе суммы заказа
- Расчёт НДС (если применимо) - в Кыргызстане 10%
- Учёт промокодов при их наличии
- Отображение детальной сметы: товары, скидки, доставка, налоги, итого

**Получение контактных данных пользователя:**
- ФИО получателя
- Номер телефона (+996 формат для Кыргызстана)
- Email для отправки квитанции
- Адрес доставки (с валидацией минимум 5 символов)
- Примечание к заказу (опционально)

**Валидация формы перед отправкой:**
- Все поля обязательны (кроме примечания)
- Проверка формата телефона и email
- Проверка заполненности адреса
- Проверка выбора способа оплаты и доставки
- Блокировка отправки при ошибках валидации с показом сообщений об ошибках

#### 4. Темы оформления

**Расширенная система тем:**
- Переключение между светлой (дневной, 6am-6pm) и тёмной (ночной, 6pm-6am) темой
- Автоматическое переключение тем по времени суток (опционально)
- Сохранение выбранной темы в LocalStorage для восстановления
- Применение темы при загрузке страницы без мерцания или мигания
- Плавные переходы между темами (не более 0.3с) для комфорта глаз
- Синхронизация с системной темой операционной системы
- Отображение текущей темы в кнопке переключателя (иконка луны/солнца)
- Применение цветовых переменных CSS3 ко всем элементам интерфейса

**Параметры тем:**
- Цвет фона (основной, вторичный)
- Цвет текста (основной, вторичный)
- Цвет акцентов и кнопок
- Тень элементов
- Цвет полей формы
- Цвет бордюров и разделителей

#### 5. Информация о товарах

**Для каждого товара отображаются и хранятся:**
- Название товара с полным описанием (50-200 символов)
- Фотография товара в формате WebP/PNG с fallback
- Цена в сомах с форматированием (например, 1 450 с)
- Артикул для идентификации в системе инвентаря
- Дата добавления в каталог (форматированная, например "20 янв 2026")
- Подробное описание включающее: материал, размеры, цвет, стиль
- Наличие товара (в наличии / под заказ)
- Информация о доставке конкретного товара
- Рейтинг и отзывы (для расширения)

**Структура данных товара:**
```javascript
{
  id: "01",                           // уникальный идентификатор
  title: "Офисный стул",              // название
  art: 288528,                        // артикул
  price: 1450,                        // цена в сомах
  text: "Удобный офисный стул...",    // описание
  imgSrc: "chair(2).png",             // имя файла
  material: "Ткань + металл",         // материал
  color: "Чёрный",                    // цвет
  size: "60x60x100 см",               // размеры
  style: "Минимализм",                // стиль
  inStock: true,                      // наличие
  addedDate: new Date()               // дата добавления
}
```

#### 6. Поиск и фильтрация

**Текущие возможности:**
- Быстрый доступ к товарам по категориям через главное меню с иконками
- Отображение товаров в сетке с ясной навигацией

**Возможные расширения:**
- Полнотекстовый поиск по названию и описанию товаров
- Фильтрация товаров по цене (мин/макс диапазон)
- Фильтрация по материалу (дерево, пластик, металл, ткань)
- Фильтрация по цвету (чёрный, белый, коричневый и т.д.)

### Нефункциональные требования

#### 1. Производительность

**Требования к скорости:**
- Время загрузки страницы: не более 2 секунд на 4G подключении (LTE)
- Первый контент должен отобразиться за 500мс (First Contentful Paint)
- Быстрая отзывчивость интерфейса: не более 100мс задержки при клике
- Время перехода между категориями: не более 300мс
- Время добавления товара в корзину: не более 50мс
- Время переключения темы: плавный переход за 300мс

**Требования к размерам файлов:**
- Размер HTML: ~10KB после минимизации
- Размер CSS: ~30KB после минимизации и сжатия
- Размер JavaScript: ~50KB после минимизации
- Общий размер приложения: < 100KB (без изображений)
- Размер каждого изображения товара: < 200KB в формате WebP, < 300KB PNG

**Требования к оптимизации:**
- Использование CSS Grid и Flexbox вместо таблиц
- Event delegation для обработки событий
- Кэширование вычислений (особенно расчёт доставки)
- Ленивая загрузка изображений (loading="lazy")
- Минимизация редисплея страницы (reflow/repaint)

#### 2. Совместимость браузеров

**Поддерживаемые браузеры и версии:**
- Google Chrome 90+ (Desktop и мобильная версия)
- Mozilla Firefox 88+ (Desktop и мобильная версия)
- Apple Safari 14+ (Desktop) и iOS Safari 14+ (iPhone/iPad)
- Microsoft Edge 90+
- Opera 76+
- Samsung Internet 14+ (Android)

**Требования к совместимости:**
- Работоспособность всех функций во всех браузерах
- Отсутствие ошибок консоли браузера
- Правильное отображение в режимах совместимости
- Поддержка стандартных API (ES6+, DOM API, LocalStorage)
- Корректное отображение при отключенном JavaScript (graceful degradation)

**Тестирование совместимости:**
- На реальных устройствах или эмуляторах (BrowserStack, LambdaTest)
- Проверка на предыдущих версиях браузеров за 2-3 года
- Сценарий: медленное интернет-соединение (3G/4G)
- Сценарий: старые процессоры и ограниченная память

#### 3. Мобильность и адаптивность

**Точки разрыва (Breakpoints):**
- **320px - 479px:** мобильные телефоны (узкие экраны)
- **480px - 767px:** мобильные телефоны (стандартные)
- **768px - 1023px:** планшеты (портретная ориентация)
- **1024px - 1365px:** планшеты (ландшафт) и маленькие ноутбуки
- **1366px - 1919px:** стандартные десктопы
- **1920px+:** мониторы высокого разрешения (2K, 4K)

**Требования к адаптивности:**
- Адаптивный дизайн для экранов от 320px до 2560px
- Оптимизированная навигация для мобильных устройств (пальцевые сенсорные элементы)
- Сенсорные элементы управления размером не менее 44x44px (по стандарту Apple/Google)
- Оптимизированные поля формы для мобильных устройств
- Вертикальная прокрутка без горизонтальной (не должно быть overflow по X)
- Правильное использование viewport meta тега: `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=5">`

**Требования к производительности на мобильных устройствах:**
- Работоспособность на устройствах с 1GB RAM
- Оптимизация для процессоров ARM (смартфоны)
- Быстрое соединение по мобильной сети (3G, LTE)
- Минимизация потребления трафика

**Тестирование на мобильных устройствах:**
- iPhone (SE, 12, 14 Pro Max)
- Android флагманы (Samsung Galaxy S21, Pixel 6)
- Android бюджетные устройства (Xiaomi, Redmi)
- Планшеты (iPad, Samsung Galaxy Tab)

#### 4. Хранение данных

**Использование LocalStorage:**
- Сохранение корзины покупок (максимум 50-100 товаров)
- Сохранение выбранной темы (1 значение: light/dark)
- Сохранение последней просмотренной категории
- Сохранение контактных данных пользователя (при согласии)

**Ограничения и требования:**
- Объём данных не должен превышать 5MB (стандартный лимит localStorage)
- Регулярная очистка устаревших данных (старше 1 месяца)
- Обработка ошибок при превышении лимита QuotaExceededError
- Использование версионирования данных для совместимости
- Резервное копирование важных данных (корзина)

**Структура LocalStorage:**
```javascript
localStorage = {
  'userCart': JSON.stringify({
    items: [...],
    timestamp: Date.now(),
    version: '1.0'
  }),
  'theme': 'dark',
  'lastCategory': 'chairs',
  'userPreferences': JSON.stringify({
    expandedInfo: true,
    compactMode: false
  })
}
```

#### 5. Доступность (Accessibility)

**Требования WCAG 2.1 Level AA:**
- Семантический HTML5 для поддержки screen readers (NVDA, JAWS, VoiceOver)

## ТЕХНИЧЕСКИЕ РЕШЕНИЯ

### Выбранные технологии

| Компонент | Технология | Обоснование |
|-----------|-----------|------------|
| **Разметка** | HTML5 | Семантическая структура, формы, медиа элементы, поддержка всеми браузерами |
| **Стилизация** | CSS3 | Flexbox/Grid для макета, переменные для тем, медиа-запросы для адаптива, анимации |
| **Логика** | JavaScript ES6+ | Vanilla JS без библиотек для быстрой загрузки, простоты и полного контроля |
| **Хранилище** | LocalStorage API | Встроенный API браузера, простой интерфейс, надёжное сохранение до 5MB |
| **Сборка** | Нет | Нативный JavaScript, отсутствие зависимостей, минимальные инструменты |
| **Данные товаров** | JSON/JavaScript | Лёгкий формат, встроенная поддержка, простое преобразование в JS объекты |

### Почему именно эти технологии?

**HTML5 вместо XHTML:**
- Более современный и гибкий
- Нативная поддержка медиа элементов (`<audio>`, `<video>`)
- Встроенные элементы валидации формы
- Лучшая поддержка accessibility

**CSS3 вместо CSS2 и препроцессоров (SASS/LESS):**
- Нативная поддержка всеми современными браузерами
- CSS переменные (--var) для динамической смены тем
- CSS Grid для сложных макетов
- Не требуется процесс сборки, можно использовать напрямую

**Vanilla JavaScript вместо фреймворков (React, Vue, Angular):**
- Меньше размер финального приложения (50KB вместо 200-300KB)
- Быстрее загрузка и выполнение (нет парсинга JSX, виртуального DOM)
- Проще отладка (можно видеть весь код)
- Лучше подходит для небольшого приложения
- Нет зависимостей от версий библиотек

**LocalStorage вместо cookie/sessionStorage:**
- Больший размер (5MB вместо 4KB для cookies)
- Синхронный доступ (нет задержек)
- Простой API (getItem/setItem/removeItem)
- Нет отправки с каждым запросом (экономия трафика)
- Лучшая безопасность (не передаётся на сервер)

**Структура cart.js (логика корзины):**
```javascript
class CartManager {
  constructor() {
    this.items = [];
    this.listeners = [];  // для подписки на изменения
    this.maxItems = 100;
    this.minQuantity = 1;
  }
  
  // Добавление товара
  addItem(product) {
    const existing = this.items.find(i => i.id === product.id);
    if (existing) {
      existing.quantity += 1;
    } else {
      this.items.push({...product, quantity: 1});
    }
    this.save();
    this.notify();
  }
  
  // Удаление товара
  removeItem(productId) {
    this.items = this.items.filter(i => i.id !== productId);
    this.save();
    this.notify();
  }
  
  // Изменение количества
  updateQuantity(productId, quantity) {
    const item = this.items.find(i => i.id === productId);
    if (item) {
      if (quantity < this.minQuantity) quantity = this.minQuantity;
      if (quantity > this.maxItems) quantity = this.maxItems;
      item.quantity = quantity;
      this.save();
      this.notify();
    }
  }
  
  // Получить общую стоимость
  getTotal() {
    return this.items.reduce((sum, item) => sum + item.price * item.quantity, 0);
  }
  
  // Получить количество товаров
  getTotalItems() {
    return this.items.reduce((sum, item) => sum + item.quantity, 0);
  }
  
  // Очистка корзины
  clear() {
    this.items = [];
    this.save();
    this.notify();
  }
  
  // Сохранение в localStorage
  save() {
    localStorage.setItem('cart', JSON.stringify(this.items));
  }
  
  // Уведомление подписчиков об изменении
  notify() {
    this.listeners.forEach(callback => callback(this.items));
  }
  
  // Подписка на изменения
  subscribe(callback) {
    this.listeners.push(callback);
  }
}
```

**Структура ChangeTheme.js (управление темой):**
```javascript
class ThemeManager {
  constructor(storageKey = 'theme') {
    this.storageKey = storageKey;
    this.currentTheme = localStorage.getItem(this.storageKey) || 'light';
    this.themes = {
      light: { bg: '#ffffff', text: '#000000' },
      dark: { bg: '#1a1a1a', text: '#e0e0e0' }
    };
  }
  
  // Применить выбранную тему
  apply(theme) {
    if (!this.themes[theme]) return;
    
    this.currentTheme = theme;
    document.body.classList.remove('light-theme', 'dark-theme');
    document.body.classList.add(`${theme}-theme`);
    document.documentElement.setAttribute('data-theme', theme);
    
    localStorage.setItem(this.storageKey, theme);
    this.dispatchEvent();
  }
  
  // Переключить тему
  toggle() {
    const newTheme = this.currentTheme === 'light' ? 'dark' : 'light';
    this.apply(newTheme);
  }
  
  // Отправить событие об изменении
  dispatchEvent() {
    const event = new CustomEvent('themeChanged', {
      detail: { theme: this.currentTheme }
    });
    document.dispatchEvent(event);
  }
  
  // Получить текущую тему
  getCurrent() {
    return this.currentTheme;
  }
}
```

#### 2. LocalStorage для постоянного хранения

**Стратегия сохранения:**
```javascript
// 1. Сохранение с версионированием
function saveCart(items) {
  const data = {
    version: '1.0',  // для будущих миграций
    timestamp: Date.now(),
    items: items,
    checksum: calculateChecksum(items)  // для проверки целостности
  };
  localStorage.setItem('cart', JSON.stringify(data));
}

// 2. Восстановление с проверкой целостности
function loadCart() {
  try {
    const saved = localStorage.getItem('cart');
    if (!saved) return [];
    
    const data = JSON.parse(saved);
    
    // Проверка версии
    if (data.version !== '1.0') {
      console.warn('Несовместимая версия данных');
      return [];
    }
    
    // Проверка контрольной суммы
    if (data.checksum !== calculateChecksum(data.items)) {
      console.error('Данные повреждены');
      return [];
    }
    
    // Проверка давности данных (старше 1 месяца)
    if (Date.now() - data.timestamp > 30 * 24 * 60 * 60 * 1000) {
      localStorage.removeItem('cart');
      return [];
    }
    
    return data.items;
  } catch (error) {
    console.error('Ошибка загрузки корзины:', error);
    return [];
  }
}

// 3. Обработка ошибки превышения лимита
function saveWithErrorHandling(key, value) {
  try {
    localStorage.setItem(key, JSON.stringify(value));
  } catch (error) {
    if (error.name === 'QuotaExceededError') {
      console.warn('Превышен лимит LocalStorage, очистка старых данных');
      clearOldData();
      localStorage.setItem(key, JSON.stringify(value));
    } else {
      throw error;
    }
  }
}
```

```javascript
function calculateDelivery(orderTotal) {
  const deliveryThreshold = 50000;      // пороговая сумма
  const standardDeliveryFee = 2500;     // стоимость доставки
  const expressDeliveryFee = 5000;      // экспресс доставка
  
  const result = {
    standard: {
      cost: orderTotal >= deliveryThreshold ? 0 : standardDeliveryFee,
      text: orderTotal >= deliveryThreshold ? 'Бесплатно' : `${standardDeliveryFee} с`,
      days: orderTotal >= deliveryThreshold ? '3-5' : '5-7'
    },
    express: {
      cost: expressDeliveryFee,
      text: `${expressDeliveryFee} с`,
      days: '1-2'
    },
    qualifying: orderTotal >= deliveryThreshold,
    remaining: Math.max(0, deliveryThreshold - orderTotal)
  };
  
  if (result.remaining > 0) {
    result.message = `До бесплатной доставки осталось ${result.remaining} с`;
  }
  
  return result;
}
```

### Пример 3: Переключение темы

```javascript
// Класс для управления темой
class ThemeManager {
  constructor(storageKey = 'theme') {
    this.storageKey = storageKey;
    this.currentTheme = localStorage.getItem(this.storageKey) || 'light';
    this.themeButton = document.getElementById('theme-toggle');
    this.init();
  }
  
  init() {
    this.applyTheme();
    this.attachEventListeners();
  }
  
  applyTheme() {
    // Удалить оба класса
    document.body.classList.remove('light-theme', 'dark-theme');
    
    // Добавить нужный класс
    document.body.classList.add(`${this.currentTheme}-theme`);
    
    // Сохранить в localStorage
    localStorage.setItem(this.storageKey, this.currentTheme);
    
    // Обновить кнопку
    this.updateButton();
    
    // Уведомить об изменении
    this.dispatchChangeEvent();
  }
  
  toggle() {
    this.currentTheme = this.currentTheme === 'light' ? 'dark' : 'light';
    this.applyTheme();
  }
  
  updateButton() {
    const icon = this.currentTheme === 'dark' ? '☀️' : '🌙';
    const label = this.currentTheme === 'dark' ? 'Светлая тема' : 'Тёмная тема';
    
    this.themeButton.textContent = icon;
    this.themeButton.setAttribute('aria-label', label);
    this.themeButton.setAttribute('title', label);
  }
  
  attachEventListeners() {
    this.themeButton.addEventListener('click', () => this.toggle());
    
    // Слушать системные предпочтения (опционально)
    if (window.matchMedia) {
      const darkModeQuery = window.matchMedia('(prefers-color-scheme: dark)');
      darkModeQuery.addEventListener('change', (e) => {
        this.currentTheme = e.matches ? 'dark' : 'light';
        this.applyTheme();
      });
    }
  }
  
  dispatchChangeEvent() {
    const event = new CustomEvent('themeChanged', {
      detail: { theme: this.currentTheme }
    });
    document.dispatchEvent(event);
  }
}

// Применение при загрузке страницы

  });
```
